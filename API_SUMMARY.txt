1. ENDPOINT A: STUDENT PORTAL (Single Resume In-Depth Analysis + Gemini AI Feedback)
================================================================================
Route:          /api/student/analyze
Method:         POST
Content-Type:   multipart/form-data
Description:    Analyzes a single student resume against a job description.
                1. Extracts skills using custom BiLSTM NER + TF-IDF scorer.
                2. Connects to Gemini API to generate personalized feedback
                   (candidate summary, improvement bullet points, and genuine score).

EXPECTED PAYLOAD (FormData):
--------------------------------------------------------------------------------
Field Name        | Type             | Required | Description
------------------|------------------|----------|-------------------------------
resume            | File (.pdf)      | Yes      | Candidate resume PDF file
job_description   | Text (string)    | Yes      | Target job description text
job_role          | Text (string)    | No       | Target job title (defaults to
                  |                  |          | "Software Engineer")

REACT / JAVASCRIPT CALL EXAMPLE:
--------------------------------------------------------------------------------
const formData = new FormData();
formData.append('resume', selectedPdfFile);
formData.append('job_description', jobDescriptionText);
formData.append('job_role', 'Full Stack AI Engineer'); // optional

const response = await axios.post('http://localhost:8000/api/student/analyze', formData, {
  headers: { 'Content-Type': 'multipart/form-data' },
});
console.log(response.data);

ERROR RESPONSES:
--------------------------------------------------------------------------------
400 Bad Request:
- Empty job description: {"detail": "Job description cannot be empty."}
- Non-PDF file:          {"detail": "Invalid file format for '...'. Only PDF files (.pdf) are supported."}
- Empty PDF:             {"detail": "Uploaded file '...' is empty."}

500 Internal Server Error:
- Pipeline failure:      {"detail": "An error occurred while processing '...': <error_message>"}

2. ENDPOINT B: RECRUITER PORTAL (Bulk Candidate Screening & Leaderboard)
================================================================================
Route:          /api/recruiter/bulk-rank
Method:         POST
Content-Type:   multipart/form-data
Description:    Evaluates multiple candidate resumes against a single job description.
                Runs the BiLSTM NER + TF-IDF pipeline and returns a sorted leaderboard
                array (highest Final Match % to lowest). Non-PDF or corrupt files are
                caught and recorded under 'skipped_files' without failing the batch.
                (Note: LLM coaching feedback is excluded for recruiter bulk speed).

EXPECTED PAYLOAD (FormData):
--------------------------------------------------------------------------------
Field Name        | Type             | Required | Description
------------------|------------------|----------|-------------------------------
resumes           | File List (.pdf) | Yes      | Multiple candidate resume files
                  |                  |          | (append each file using key 'resumes')
job_description   | Text (string)    | Yes      | Single target job description

REACT / JAVASCRIPT CALL EXAMPLE:
--------------------------------------------------------------------------------
const formData = new FormData();
// Append each PDF file under the same 'resumes' key
Array.from(pdfFilesList).forEach((file) => {
  formData.append('resumes', file);
});
formData.append('job_description', jobDescriptionText);

const response = await axios.post('http://localhost:8000/api/recruiter/bulk-rank', formData, {
  headers: { 'Content-Type': 'multipart/form-data' },
});
console.log(response.data);
